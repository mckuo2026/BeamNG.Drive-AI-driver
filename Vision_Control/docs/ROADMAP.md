# Roadmap

## v1.0

- English-first project package.
- Multilingual UI.
- Window-only and DXGI capture backends.
- Adaptive road segmentation fallback.
- Virtual gamepad output.
- README, changelog, and setup scripts.

- Add automatic ROI calibration.

- Add a lightweight ONNX road/obstacle model.
- Add optional depth or obstacle-distance estimation.
- Add recovery behavior for stuck or off-road states.
